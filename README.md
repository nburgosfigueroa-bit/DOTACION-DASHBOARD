# Dashboard de Dotación · AKRO

> Herramienta visual para revisar dotación, ausencias, vacaciones, reemplazos y cargos críticos.

## 👥 Acceso directo

### [ABRIR EL DASHBOARD DE DOTACIÓN](https://nburgosfigueroa-bit.github.io/DOTACION-DASHBOARD/)

[Ver repositorio en GitHub](https://github.com/nburgosfigueroa-bit/DOTACION-DASHBOARD)

## 1. ¿Qué hace este proyecto?

Permite cargar una planilla Excel y visualizar indicadores de dotación en un solo lugar. Incluye vistas de trabajadores, ausencias, vacaciones, reemplazos, cargos críticos y reportes.

## 2. Información disponible

- Dotación general.
- Trabajadores y distribución operacional.
- Ausencias y vacaciones.
- Reemplazos y cargos críticos.
- Reportes de apoyo para la gestión.

## 3. Automatizaciones

- **Carga de Excel:** el archivo se procesa directamente en el navegador del usuario.
- **Indicadores:** las tablas y gráficos se recalculan después de cargar la información.
- **Publicación web:** GitHub Pages entrega el acceso público al tablero.
- **Privacidad:** la planilla seleccionada no debe incorporarse al repositorio público.
